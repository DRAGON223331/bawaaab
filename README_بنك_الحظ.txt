بنك الحظ — نسخة لوحة كاملة بلا قائمة جانبية

التشغيل: افتح index.html في Chrome أو Edge.

المزايا:
- من 2 إلى 6 لاعبين، واختيار لون سيارة مختلف لكل لاعب قبل البداية.
- قطع سيارات سباق كلاسيكية مستوحاة من سيارات اللعب المعدنية القديمة ذات المقعد المكشوف والشبكة الأمامية الرأسية.
- لوحة مرسومة بالكامل بـCSS وبها 40 خانة قابلة للتفاعل.
- حجرَا النرد في منتصف اللوحة، مع حركة دوران وقفز وتبديل الأوجه أثناء الرمية.
- تحريك السيارات خطوة بخطوة حول اللوحة.
- لا توجد قائمة جانبية أثناء اللعب؛ حالة الدور وأزراره في منتصف اللوحة.
- شراء العقارات يظهر كإشعار منبثق عند الوقوف على مكان غير مملوك، مع زري شراء وتخطي.
- شات داخل اللعبة يجمع رسائل اللاعبين مع سجل الأحداث تلقائيًا، مع إمكانية مسح السجل.
- إدارة العقارات في نافذة مستقلة، ومنها البناء والرهن وفك الرهن.
- رصيد البداية 1200 جنيه لكل لاعب.
- نقود ورقية ملونة بفئات 1، 5، 10، 20، 50، 100، 500، 1000، 2000 جنيه، مع عرضها أمام اللاعبين.
- المرور من البداية +250 جنيه، وأجر مدير البنك 50 جنيه عند المرور حسب الاختيار.
- محطة البنزين: السعر 300 جنيه، والإيجار 40 جنيهًا.
- المنشآت: جراج ثم استراحة ثم سوق.
- السجن: دفع 50 جنيهًا أو تخطي دورين.
- بطاقات حظك والمحكمة.
- حفظ اللعبة واستكمالها من نفس المتصفح.

الصوت:
- صوت رمي النرد: assets/audio/dice.mp3 (محلي، يعمل بدون إنترنت).
- موسيقى الخلفية: assets/audio/bgmusic.mp3 (تتكرر تلقائيًا، وتبدأ عند أول ضغطة، وتنخفض لحظة رمي النرد).
- زران في الأعلى: «المؤثرات» و«الموسيقى»، ويُحفظ اختيارك في المتصفح.
- باقي المؤثرات (عملات، كروت، نقر) ما زالت تحتاج إنترنت.
- مهم: احتفظ بمجلد assets بجانب ملف HTML.

ملاحظة الشات: الرسائل محلية على نفس الجهاز/المتصفح، وليست شاتًا عبر الإنترنت بين أجهزة مختلفة.

تحديث قطع اللاعبين (9 نوفمبر 2026):
- تم استبدال رسومات السيارات القديمة بصور سيارات السباق الثلاثية الأبعاد الستة التي أُنشئت للعبة.
- تم فصل كل سيارة كصورة WebP مستقلة بخلفية شفافة، ودمج الصور الست داخل ملف HTML؛ لا تحتاج إلى مجلد صور خارجي.
- اختيار الأحمر والأزرق والأصفر والأخضر والبنفسجي والبرتقالي يحدد صورة السيارة المطابقة تلقائيًا في شاشة البداية وعلى اللوحة وفي شريط اللاعبين والنقود.


==============================
اللعب أونلاين (جديد)
==============================
اللعبة بقت تشتغل أونلاين من ٢ لـ ٦ لاعبين، كل واحد من جهازه. محتاج تشغّل سيرفر صغير (server.js) مرة واحدة.

1) تشغيل على جهازك (للتجربة أو لو كلكم على نفس الواي فاي):
   - ثبّت Node.js (نسخة 18 أو أحدث) من nodejs.org
   - افتح الطرفية داخل مجلد اللعبة واكتب:
        npm install
        npm start
   - افتح http://localhost:3000 على جهازك. لو هتستخدم WebSocket الموجود في server.js اكتب http://localhost:3000 في خانة «سيرفر مخصص»؛ ولو هتسيبها فاضية هتستخدم PeerJS المباشر.
   - أصحابك على نفس الشبكة يفتحوا http://<عنوان-جهازك>:3000، ومع وضع WebSocket يكتبوا نفس العنوان في خانة «سيرفر مخصص».

2) لعب مع أصحاب من أي مكان (اختار واحدة):
   أ) نفق مؤقت وأنت شغّال السيرفر: npx cloudflared tunnel --url http://localhost:3000
      وابعت الرابط اللي بيطلع (https://....trycloudflare.com) لأصحابك.
   ب) استضافة Node منفصلة (مثل Render.com): ارفع المجلد على GitHub، وأنشئ Web Service
      وخلّي Build Command = npm install و Start Command = npm start.
      هتاخد رابط زي https://اسمك.onrender.com؛ اكتب الرابط ده في خانة «سيرفر مخصص» داخل اللعبة.
      (الخطة المجانية قد تتوقف بعد فترة خمول، وأول اتصال قد يتأخر.)

3) طريقة اللعب أونلاين:
   - اضغط «🌐 العب أونلاين»، اكتب اسمك واختار عربيتك.
   - صاحب الغرفة يضغط «إنشاء غرفة جديدة» ويبعت الكود أو «رابط الدعوة» للباقي.
   - الباقي يفتحوا الرابط (أو يكتبوا الكود) ويضغطوا «انضمام».
   - صاحب الغرفة يضغط «ابدأ اللعب» لما الكل يكون جاهز.
   - كل لاعب يشوف فلوسه في الشريط السفلي، والأزرار بتظهر في دوره فقط.
   - لو النت فصل، الصفحة بترجع للغرفة تلقائيًا. لو لاعب قفل الصفحة تمامًا افتح نفس الرابط من نفس المتصفح.
   - ملحوظة: خانة «سيرفر مخصص» اختيارية؛ سيبها فاضية للاتصال المباشر، أو اكتب رابط خادم Node لو هتستخدمه.
   - الحفظ والاستكمال مش شغالين في الأونلاين.


==============================
أونلاين بدون سيرفر (يشتغل على Vercel / Netlify / GitHub Pages)
==============================
- لو فتحت اللعبة من موقع ثابت (زي Vercel) أو من ملف على جهازك، الأونلاين بيشتغل مباشرة بين الأجهزة (WebRTC عبر PeerJS)، ومش محتاج server.js.
- متصفح صاحب الغرفة هو «السيرفر»: لازم يفضل فاتح الصفحة طول اللعب. لو قفلها أو عمل تحديث، الغرفة بتنتهي.
- باقي اللاعبين لو فصل النت عندهم بيرجعوا تلقائيًا.
- محتاج إنترنت لكل اللاعبين (للاتصال الأولي بين الأجهزة). بعض شبكات الشركات أو المدارس بتمنع الاتصال المباشر.
- ارفع المجلد كله على Vercel كما هو (ملف index.html في الجذر). ملف .vercelignore بيستبعد server.js تلقائيًا. احذف أي vercel.json قديم.
- لو عايز تستخدم server.js على Render بدل الاتصال المباشر، اكتب رابط خدمة Render في خانة «سيرفر مخصص». ترك الخانة فاضية يشغّل وضع PeerJS المباشر.

==============================
النشر على Vercel (تجهيز مباشر)
==============================
النسخة دي مجهزة للاستضافة الثابتة على Vercel:

1) ارفع مجلد المشروع كما هو، بحيث يكون index.html و vercel.json في جذر المشروع ومجلد assets بجانبهما. لا ترفع ملف ZIP نفسه داخل مجلد فرعي ولا تختار مجلدًا لا يحتوي على index.html كـ Root Directory.
2) في إعدادات مشروع Vercel اختار Framework Preset = Other.
3) سيب Build Command و Install Command و Output Directory بدون قيمة (لا تكتب dist أو public). المشروع HTML ثابت ولا يحتاج Build.
4) اعمل Deploy. الصفحة الرئيسية هي /، والملفات الصوتية والسيارات ومكتبة PeerJS بتتحمل من /assets/.
5) في شاشة الأونلاين سيب خانة «سيرفر مخصص» فاضية. اللعبة هتستخدم PeerJS/WebRTC مباشرة، وده الوضع الافتراضي على Vercel حتى لو استخدمت Custom Domain.
6) لو عندك سيرفر Node منفصل شغال بـ server.js، اكتب رابطه في خانة «سيرفر مخصص» (مثال: https://اسم-الخدمة.onrender.com). وقتها اللعبة تستخدم WebSocket بدل الاتصال المباشر.

مهم بخصوص الأونلاين: Vercel بيستضيف ملفات اللعبة، لكن في وضع P2P صاحب الغرفة هو اللي بيشغّل منطق الغرفة من متصفحه، ولازم يفضل فاتح الصفحة طول اللعب. PeerJS Cloud بيعمل signaling مجاني، بينما بيانات اللعب بتنتقل مباشرة بين الأجهزة. بعض شبكات الإنترنت أو إعدادات NAT الصارمة ممكن تمنع الاتصال المباشر؛ لذلك مفيش طريقة تضمن نجاح الاتصال على كل شبكة بنسبة 100%. عند حدوث ده جرّب شبكة مختلفة أو استخدم سيرفر Node مخصص.

اختبار سريع بعد النشر: افتح رابط الموقع، ثم افتح /assets/vendor/peerjs.min.js وتأكد أن المتصفح يعرض ملف JavaScript، وبعدها جرّب إنشاء غرفة من جهاز والانضمام إليها من جهاز آخر. لازم يكون الجهازان متصلين بالإنترنت، وصاحب الغرفة يفضل فاتح الصفحة.
